# Frontend Application

Фронтенд приложение для системы управления инвестиционными сигналами и карточками компаний.

## Введение

Данный проект представляет собой клиентское веб-приложение, разработанное с использованием современных технологий веб-разработки. Приложение обеспечивает интерфейс для работы с инвестиционными сигналами, управления карточками компаний, фильтрации данных и взаимодействия с участниками инвестиционного процесса.

## Технологический стек

Проект построен на следующих технологиях и библиотеках:

- **Framework**: Next.js 16 с использованием App Router архитектуры
- **UI Library**: React 19
- **Language**: TypeScript для обеспечения типобезопасности
- **Styling**: Tailwind CSS 4.0 для стилизации компонентов
- **UI Components**: shadcn/ui в сочетании с Radix UI для создания доступных интерфейсных компонентов
- **State Management**: Zustand для локального управления состоянием, Apollo Client для управления состоянием GraphQL
- **GraphQL**: Apollo Client для выполнения запросов и мутаций к GraphQL API
- **Forms**: React Hook Form в сочетании с Zod для валидации форм
- **Icons**: Tabler Icons и Lucide React для иконографики

## Функциональные возможности

Приложение реализует следующий набор функциональных возможностей:

### Аутентификация и авторизация

Система входа, регистрации и управления пользовательскими сессиями с поддержкой обновления токенов доступа.

### Персональный фид

Оптимизированный персональный фид пользователя, содержащий карточки сигналов с учетом пользовательских предпочтений и фильтров.

### Фильтрация и поиск

Расширенная система фильтрации данных по различным критериям:
- Категории компаний
- Стадии развития
- Типы участников
- Статусы раундов инвестирования
- Временные диапазоны
- Количество сигналов

### Сохраненные фильтры

Функционал создания, редактирования, применения и удаления сохраненных фильтров с возможностью установки фильтра по умолчанию.

### Управление папками

Организация карточек в структурированные папки:
- Избранные карточки
- Удаленные карточки
- Пользовательские папки

### Управление участниками

Просмотр и управление различными типами участников инвестиционного процесса:
- Ангел-инвесторы
- Венчурные фонды и инвесторы
- Синдикаты, фонды, платформы и сообщества
- Основатели и предприниматели

### Заметки

Добавление, редактирование и удаление заметок к карточкам для персональных пометок.

### Назначения

Назначение карточек группам и участникам с отслеживанием статусов выполнения.

### Статистика и аналитика

Просмотр статистических данных по сигналам и участникам с визуализацией информации.

### Темы оформления

Поддержка переключения между темной и светлой темами оформления интерфейса.

## Установка и запуск

### Системные требования

Для работы с проектом необходимо наличие следующих инструментов:

- Node.js версии 18 или выше
- Менеджер пакетов: npm, yarn или pnpm

### Установка зависимостей

Установка всех необходимых зависимостей проекта выполняется одной из следующих команд:

```bash
npm install
# или
yarn install
# или
pnpm install
```

### Конфигурация переменных окружения

Перед запуском приложения необходимо создать файл `.env.local` в корневой директории проекта со следующим содержимым:

```env
NEXT_PUBLIC_API_BASE_URL=https://api.example.com:8000
NEXT_PUBLIC_APP_BASE_URL=https://app.example.com
```

### Запуск в режиме разработки

Для запуска приложения в режиме разработки используется команда:

```bash
npm run dev
# или
yarn dev
# или
pnpm dev
```

Приложение будет доступно по адресу http://localhost:3000

### Сборка для production

Для создания production сборки выполните следующие команды:

```bash
npm run build
npm run start
```

## Документация API

Проект использует два типа API для взаимодействия с серверной частью приложения: GraphQL API и REST API.

### GraphQL API

Полная документация по всем GraphQL запросам и мутациям представлена в файле [GRAPHQL_QUERIES.md](./GRAPHQL_QUERIES.md).

Документация включает следующую информацию:

- 17 GraphQL запросов (queries)
- 7 GraphQL мутаций (mutations)
- Описание типов данных и входных параметров
- Примеры использования запросов и мутаций
- Информацию о реализованных типах пагинации (cursor-based и page-based)
- Описание обработки ошибок и механизмов кеширования

Основные GraphQL операции:

- `userFeed` - получение персонального фида пользователя
- `participants` - запросы участников различных типов (ангелы, VC, синдикаты, основатели)
- `signalCards` - запросы карточек сигналов с различными параметрами фильтрации
- `savedFilters` - управление сохраненными фильтрами пользователя
- `groupAssignments` - получение и управление назначениями карточек группам

### REST API

Полная документация по всем REST API маршрутам представлена в файле [BACKEND_ROUTES.md](./BACKEND_ROUTES.md).

Документация включает:

- Полный список эндпоинтов бэкенда с указанием HTTP методов
- Описание параметров запросов и форматов данных
- Информацию о механизмах авторизации
- Примеры использования эндпоинтов

Основные разделы REST API:

- `/f-api/auth` - аутентификация и авторизация пользователей
- `/f-api/user` - управление профилем и настройками пользователя
- `/f-api/cards` - операции с карточками (создание, обновление, удаление, получение)
- `/f-api/folders` - управление папками для организации карточек
- `/f-api/investors` - управление участниками инвестиционного процесса
- `/f-api/feeds` - получение различных типов фидов
- `/f-api/filters` - управление фильтрами данных

## Структура проекта

Проект организован по следующей структуре директорий:

```
Front/
├── src/
│   ├── app/                    # Next.js App Router
│   │   ├── (protected)/        # Защищенные маршруты приложения
│   │   ├── (public)/           # Публичные маршруты
│   │   ├── api/                # Next.js API routes для проксирования запросов
│   │   └── auth/               # Страницы аутентификации
│   ├── components/             # Переиспользуемые компоненты
│   │   ├── ui/                 # UI компоненты на основе shadcn/ui
│   │   └── layout/             # Компоненты макета страниц
│   ├── features/               # Функциональные модули приложения
│   │   ├── all-signals/        # Модуль работы со всеми сигналами
│   │   ├── investors/          # Модуль работы с участниками/инвесторами
│   │   ├── saved-cards/        # Модуль сохраненных карточек
│   │   ├── folders/            # Модуль управления папками
│   │   └── shared/             # Общие компоненты и утилиты
│   ├── hooks/                  # Пользовательские React хуки
│   ├── lib/                    # Библиотеки и утилиты
│   │   └── graphql/            # GraphQL запросы и мутации
│   ├── contexts/               # React контексты для управления состоянием
│   ├── config/                 # Конфигурационные файлы
│   └── types/                  # TypeScript определения типов
├── public/                     # Статические файлы
├── BACKEND_ROUTES.md           # Документация REST API
├── GRAPHQL_QUERIES.md          # Документация GraphQL API
└── package.json
```

## Аутентификация

Приложение использует механизм аутентификации на основе Bearer Token:

- Токен доступа хранится в HTTP-only cookie с именем `accessToken`
- Автоматическое обновление токена доступа выполняется через эндпоинт `/f-api/auth/refresh/`
- Все запросы к API (за исключением публичных эндпоинтов) требуют наличия валидного токена авторизации

## UI Компоненты

Проект использует библиотеку [shadcn/ui](https://ui.shadcn.com/) для создания пользовательского интерфейса. Данная библиотека представляет собой коллекцию переиспользуемых компонентов, построенных на основе Radix UI и стилизованных с помощью Tailwind CSS.

Все UI компоненты расположены в директории `src/components/ui/` и могут быть настроены через файл конфигурации `components.json`.
